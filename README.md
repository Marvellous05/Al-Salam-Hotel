# Al Salam Hotel Website

A responsive, multi-page hotel website prepared for Al Salam Hotel in Bneid Al-Gar, Kuwait City.

## Included
- Home page with hotel introduction, room categories, facilities, nearby attractions and embedded Google Map
- Rooms page with three room categories and enquiry links
- Experience page for dining, pool, spa/wellness, fitness and other listed facilities
- Location page with map, directions, map location code and nearby attractions
- Contact page with a booking-enquiry form that opens a pre-filled WhatsApp message to +965 2226 3600
- Responsive mobile navigation
- English/Arabic language toggle (Arabic translation is provided for the shared navigation and primary home-page copy; remaining page content is currently English)
- Basic SEO descriptions, semantic HTML and accessible labels

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code's Live Server extension.
3. Internet access is needed for Google Fonts, remote stock photography, WhatsApp and the embedded map.

## Deploy
This is a static website. Upload the contents of this folder to a static hosting provider such as Netlify, Cloudflare Pages or GitHub Pages. No build command is required. Publish directory: the project root (the folder containing `index.html`).

## Important before publishing as the hotel's official site
This is a complete, deployable website build, but it has not been commissioned or approved by the hotel and is not yet published on a hotel-owned domain. Obtain written permission from the hotel before presenting it as the hotel's official website. Replace the illustrative stock photography with hotel-owned or licensed photographs. Confirm all room categories, amenities, accessibility details, location, contact information, policies and current operating details with hotel management. Do not add prices or claim that a reservation is confirmed unless the hotel has provided and approved that information.

The WhatsApp enquiry form opens WhatsApp and asks the guest to send the message. It does not process payments, check live availability, store enquiries, or confirm bookings. A real booking engine, payment processing, analytics or a management dashboard would require separate configuration and approval.
